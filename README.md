# Consultorio: citas y cierre diario de caja

Trabajo final de Fundamentos de Programación 1 (UPC EPE, NRC 631).

## Cómo ejecutar

```
python consultorio.py
```

El programa pregunta qué día hábil del mes es hoy (del 1 al 20) y muestra el menú. Trae pacientes de ejemplo en los días 1, 2 y 3.

## Cómo ejecutar las pruebas

En el menú, la opción 8 corre las 44 pruebas. Debe salir `Pruebas correctas: 44 de 44`.

## Qué hace cada opción

| Opción | Historia de usuario |
|---|---|
| 1 Reservar | HU01 Reservar una cita |
| 2 Llegó un paciente | HU02 Atender al paciente que llega |
| 3 Reprogramar o cancelar | HU03 Reprogramar o cancelar una cita |
| 4 Cierre de caja | HU04 Cierre de caja del día |
| 5 Indicadores | HU05 Indicadores del día y del mes |
| 6 Reporte de seguros | HU06 Reporte mensual para la aseguradora |
| 8 Pruebas | Comprueba las funciones con datos conocidos |
